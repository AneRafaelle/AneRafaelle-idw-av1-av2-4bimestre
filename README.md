# MeusGastos – Controle de Gastos Pessoais

Aplicação web para controle de gastos pessoais, desenvolvida como projeto do 4º bimestre (Etapas 1 e 2) com **HTML, CSS, Bootstrap 5 e JavaScript**.

**Autora:** Ane Rafaelle

## Funcionalidades

- Painel com resumo do mês: renda, gastos e saldo
- Barra de renda utilizada (muda de cor com 80% e 100% de uso)
- Gastos por categoria, com barra empilhada e cards
- Cadastro de despesas com validação (descrição, valor, categoria e data)
- Atualização da renda mensal
- Listagem em tabela, filtro por categoria e remoção de despesas
- Botão para ocultar/mostrar valores
- Feedback visual (alertas e campos inválidos) e layout responsivo

## Tecnologias

- HTML5 semântico
- CSS3 (identidade visual própria, fontes Poppins e Inter)
- Bootstrap 5.3 (via CDN)
- JavaScript (funções, arrays, eventos e manipulação do DOM)

```bash
git clone https://github.com/SEU-USUARIO/meus-gastos.git
cd meus-gastos
```

> Os dados ficam em arrays na memória, então são reiniciados ao recarregar a página.


## Etapas do projeto

- **Etapa 1:** estrutura HTML, identidade visual, responsividade com Bootstrap e interação básica com JavaScript
- **Etapa 2:** formulários, validação, funções, arrays e atualização dinâmica do DOM
